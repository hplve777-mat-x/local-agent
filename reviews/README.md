# Приёмка черновиков

Локальная модель пишет задание и отчёт в `reviews/inbox/<короткое-имя>.md`. Агент Cursor пишет вердикт в `reviews/outbox/<то же имя>.md`.

## Образец inbox

```markdown
# Короткое имя

## Задание

Что сделать. Одна задача.

## Отчёт черновика

- Изменено:
- Команда проверки:
- Результат:
- Неясно:
```

## Образец outbox

```markdown
# Короткое имя

Вердикт: принято

## Уже верно

- ...

## Правки

1. Что изменить. Готово, когда ...
```

Вердикт бывает `принято` или `на доработку`. Правки нумеруются. Новые задачи в outbox не добавляются.
